# cv.pankaz.dev

Personal resume/portfolio of Pankaz Jha, QA Automation Engineer — a single-page site styled as a Linux desktop (Catppuccin Mocha).

Live: https://cv.pankaz.dev

## Stack

- Next.js 16 (App Router, TypeScript), static export
- Tailwind CSS v4
- `motion` + `lenis` for animation and smooth scroll
- Hosted on Cloudflare

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/
```

Site copy lives in `src/content/site.ts`.
